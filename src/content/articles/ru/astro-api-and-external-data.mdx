Astro делает работу с внешними данными невероятно простой и эффективной. Поскольку компоненты Astro выполняются на сервере во время сборки (или во время запроса в режиме SSR), вы можете безопасно получать данные из любого API, базы данных или Headless CMS прямо во Frontmatter вашего компонента.

В этом уроке мы рассмотрим, как получать данные, обрабатывать асинхронные операции и рендерить внешний контент.

## Глобальная функция `fetch()`

Astro предоставляет доступ к глобальной функции `fetch()` во Frontmatter всех ваших компонентов. Она работает точно так же, как API `fetch` в браузере, но выполняется безопасно на бэкенде.

### Базовое получение данных

Чтобы получить данные, просто используйте `await` на верхнем уровне внутри скрипта компонента (область между `---`).

```astro
---
// Пример: src/pages/users.astro
const response = await fetch('https://jsonplaceholder.typicode.com/users');
const users = await response.json();
---

<h1>Каталог пользователей</h1>
<ul>
  {users.map((user) => (
    <li>
      <strong>{user.name}</strong> ({user.email})
    </li>
  ))}
</ul>
```

Когда Astro собирает ваш сайт, он выполняет HTTP-запрос, ждет ответа, генерирует HTML с данными и отправляет в браузер *только HTML*. JavaScript, использованный для получения данных, полностью удаляется.

## Безопасность и API Ключи

Поскольку код Frontmatter никогда не попадает в браузер, вы можете безопасно использовать секретные API ключи, пароли баз данных и переменные окружения, не раскрывая их клиенту.

Чтобы использовать переменные окружения, создайте файл `.env` в корне вашего проекта:

```env
# .env
SECRET_API_KEY=my-super-secret-key
```

Затем вы можете получить к нему доступ в ваших файлах `.astro` с помощью `import.meta.env`:

```astro
---
const apiKey = import.meta.env.SECRET_API_KEY;

const response = await fetch('https://api.mycms.com/posts', {
  headers: {
    'Authorization': `Bearer ${apiKey}`
  }
});
const data = await response.json();
---
```

<Alert type="warning">
Никогда не добавляйте префикс `PUBLIC_` к секретным переменным (например, `PUBLIC_API_KEY`), так как Astro сделает их доступными для клиентского JavaScript. Сохраняйте переменные только для сервера без префикса `PUBLIC_`!
</Alert>

## Получение данных для динамических маршрутов

Если вы используете динамические маршруты (например, `[id].astro`) и SSG (статическую генерацию сайтов), вам нужно получать данные внутри функции `getStaticPaths()`.

`getStaticPaths` должна возвращать массив объектов, где каждый объект содержит ключ `params` для определения маршрута и необязательный ключ `props` для передачи данных на страницу.

```astro
---
// src/pages/posts/[id].astro
export async function getStaticPaths() {
  const response = await fetch('https://jsonplaceholder.typicode.com/posts');
  const posts = await response.json();

  return posts.map((post) => {
    return {
      params: { id: post.id.toString() },
      props: { post }, // Передаем данные поста напрямую!
    };
  });
}

// Получаем props, переданные из getStaticPaths
const { post } = Astro.props;
---

<article>
  <h1>{post.title}</h1>
  <p>{post.body}</p>
</article>
```

Передавая данные через `props`, вы избегаете необходимости получать одни и те же данные дважды (один раз для генерации маршрута, и второй раз для контента страницы).

## GraphQL и Headless CMS

Astro абсолютно независим от источника данных. Вы можете использовать любую Headless CMS (Contentful, Sanity, Strapi, WordPress) или GraphQL endpoint.

Запрос GraphQL — это просто HTTP POST запрос:

```astro
---
const query = `
  {
    allPosts {
      title
      slug
    }
  }
`;

const response = await fetch('https://my-graphql-endpoint.com', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ query }),
});

const json = await response.json();
const posts = json.data.allPosts;
---
```

## Итоги

- Astro предоставляет глобальную функцию `fetch()`, которая выполняется во время сборки.
- Вы можете безопасно использовать API ключи во Frontmatter, потому что этот код не отправляется клиенту.
- Выражение `await` на верхнем уровне полностью поддерживается в компонентах Astro.
- Для динамических маршрутов получайте данные внутри `getStaticPaths()` и передавайте их через `props`.

В следующем уроке мы рассмотрим Server-Side Rendering (SSR) и API Endpoints, что превратит Astro из генератора статических сайтов в полноценный full-stack веб-фреймворк!
