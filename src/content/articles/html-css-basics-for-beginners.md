# Основы HTML и CSS для начинающих

Если вы только начинаете свой путь в веб-разработке, два главных термина, с которыми вы столкнетесь, — это **HTML** и **CSS**. Это фундаментальные строительные блоки любого сайта в интернете. В этой статье мы разберем, что это такое и как они взаимодействуют.


## Что такое HTML?

**HTML (HyperText Markup Language)** — это язык гипертекстовой разметки. Представьте, что это "скелет" вашего сайта. Он говорит браузеру, где находится заголовок, где абзац текста, а где картинка или ссылка.

Пример простого HTML-кода:

```html
<h1>Добро пожаловать на мой сайт!</h1>
<p>Это мой первый абзац текста. Я только учусь создавать веб-страницы.</p>
<img src="my-photo.jpg" alt="Моя фотография">
```

Здесь мы использовали теги `<h1>` для главного заголовка, `<p>` для абзаца и `<img>` для изображения.

## Что такое CSS?

**CSS (Cascading Style Sheets)** — это каскадные таблицы стилей. Если HTML — это скелет, то CSS — это "одежда" и "макияж" вашего сайта. С помощью CSS вы можете изменять цвета, шрифты, размеры элементов, их расположение на странице и даже добавлять анимации.

Пример CSS-кода для нашего HTML:

```css
h1 {
  color: #ff6f61;
  font-family: 'Arial', sans-serif;
  text-align: center;
}

p {
  font-size: 18px;
  line-height: 1.6;
}
```

Этот код сделает наш заголовок ярким, изменит его шрифт и выровняет по центру, а текст абзаца станет более читаемым.

## Как они работают вместе?

HTML и CSS разделяют структуру (содержимое) и представление (внешний вид). Это позволяет разработчикам легко менять дизайн сайта, не переписывая при этом весь текст и не меняя структуру. Обычно CSS-код выносится в отдельный файл, который подключается к HTML-документу.

Начните экспериментировать! Создайте простой HTML-файл, добавьте немного текста и попробуйте стилизовать его с помощью CSS. Вы удивитесь, как быстро можно достичь классных результатов!
