**Astro компоненты** (файлы с расширением `.astro`) — это основные строительные блоки любого Astro проекта. Они представляют собой HTML шаблоны с возможностью внедрения серверной логики.

Главное правило: **Astro-компоненты рендерятся исключительно на сервере (или во время сборки)**. Они никогда не отправляют свой JavaScript в браузер. Это значит, что вы можете писать в них тяжелую логику, обращаться к базе данных или парсить файлы, и это никак не замедлит загрузку страницы у пользователя!

## Анатомия `.astro` файла

Каждый компонент состоит из двух основных частей: **Скрипта компонента (Frontmatter)** и **Шаблона компонента**.

```astro
---
// 1. Скрипт компонента (Frontmatter)
// Этот код выполняется ТОЛЬКО на сервере!
const name = "Astro";
const isAwesome = true;
---

<!-- 2. Шаблон компонента -->
<!-- Этот HTML отправится в браузер -->
<div>
  <h1>Привет, {name}!</h1>
  {isAwesome && <p>Astro просто супер!</p>}
</div>
```

Блок, окруженный тремя дефисами `---`, называется **Frontmatter**. Если вы знакомы с Markdown, вы уже видели такой синтаксис. Внутри него можно писать любой валидный TypeScript или JavaScript код.

## Импорт и использование других компонентов

Вы можете создавать переиспользуемые кусочки UI (например, `<Header />`, `<Button />`, `<Card />`) и использовать их внутри других компонентов или страниц.

```astro
---
// src/pages/index.astro
// Импортируем компонент (путь должен быть относительным или через alias)
import Button from '../components/Button.astro';
---

<main>
  <h1>Моя страница</h1>
  <!-- Используем компонент в шаблоне -->
  <Button />
  <Button />
</main>
```

## Передача свойств (Props)

Компоненты были бы бесполезны, если бы мы не могли передавать им данные. В Astro это делается с помощью глобального объекта `Astro.props`.

Лучшая практика — всегда типизировать ваши Props с помощью TypeScript. Для этого нужно создать интерфейс `Props` внутри Frontmatter.

Пример компонента `Greeting.astro`:
```astro
---
// Определяем типы для ожидаемых свойств
interface Props {
  name: string;
  greeting?: string; // необязательное свойство
}

// Деструктуризируем свойства из Astro.props
// И задаем значение по умолчанию для greeting
const { name, greeting = "Здравствуйте" } = Astro.props;
---

<div class="card">
  <h2>{greeting}, {name}!</h2>
</div>
```

Использование этого компонента:
```astro
---
import Greeting from '../components/Greeting.astro';
---

<!-- Обязательное свойство name передано -->
<Greeting name="Алексей" /> 

<!-- Переданы оба свойства -->
<Greeting name="Иван" greeting="Привет" />
```

## Слоты (`<slot />`) и композиция компонентов

Props отлично подходят для передачи простых данных (строк, чисел, массивов). Но что, если вы хотите передать внутрь компонента **целый кусок HTML-кода или другие компоненты**?

Для этого используются **Слоты**. Тег `<slot />` работает как "заполнитель", куда будет вставлен контент, переданный между открывающим и закрывающим тегами компонента.

Пример `Card.astro`:
```astro
---
interface Props {
  title: string;
}
const { title } = Astro.props;
---

<article class="card">
  <h3>{title}</h3>
  <div class="card-content">
    <!-- Сюда попадет весь вложенный контент -->
    <slot /> 
  </div>
</article>
```

Использование:
```astro
---
import Card from '../components/Card.astro';
---

<Card title="О слотах">
  <!-- Этот абзац и кнопка окажутся внутри <slot /> -->
  <p>Слоты позволяют создавать гибкие обертки.</p>
  <button>Подробнее</button>
</Card>
```

### Запасной контент (Fallback content)

Вы можете поместить контент внутрь самого тега `<slot>`. Он будет отображаться только в том случае, если при вызове компонента ничего не передали.

```astro
<slot>
  <p>Пользователь не передал никакого контента!</p>
</slot>
```

### Именованные слоты (Named slots)

Если вашему компоненту нужно несколько областей для вставки контента (например, шапка, основное тело и подвал), вы можете дать слотам имена с помощью атрибута `name`.

Пример `Layout.astro`:
```astro
<div class="layout">
  <header>
    <slot name="header" />
  </header>
  
  <main>
    <!-- Слот по умолчанию (без имени) -->
    <slot />
  </main>
  
  <footer>
    <slot name="footer" />
  </footer>
</div>
```

Чтобы передать контент в конкретный слот, добавьте атрибут `slot="..."` к любому HTML-элементу:

```astro
---
import Layout from '../components/Layout.astro';
---

<Layout>
  <!-- Пойдет в слот name="header" -->
  <h1 slot="header">Заголовок страницы</h1>
  
  <!-- Пойдет в слот по умолчанию -->
  <p>Это основной контент страницы.</p>
  
  <!-- Пойдет в слот name="footer" -->
  <p slot="footer">© 2026 Все права защищены</p>
</Layout>
```
