Одной из главных фич Astro является его подход к JavaScript: **Zero JS by default** (Ноль JavaScript по умолчанию). 

Astro рендерит ваш HTML на сервере и вырезает весь JavaScript, который использовался для генерации компонента. Это делает сайты невероятно быстрыми. Но что, если вам нужна интерактивность на клиенте (слайдеры, модальные окна, счетчики)?

## 1. Использование тега `<script>`

Самый простой способ добавить клиентский JS в компонент Astro — использовать стандартный тег `<script>`. 

```astro
---
// Серверный код (не попадет в браузер)
const message = "Привет с сервера!";
---

<button id="my-button">Нажми меня</button>

<script>
  // Этот код будет выполнен в браузере!
  const button = document.getElementById('my-button');
  
  button.addEventListener('click', () => {
    alert('Кнопка нажата!');
  });
</script>
```

### Как Astro обрабатывает скрипты:
По умолчанию Astro **компилирует, бандлит (склеивает) и минифицирует** все теги `<script>`. 
Более того, если один и тот же компонент используется на странице 5 раз, Astro достаточно умен, чтобы загрузить скрипт для него **только один раз**. 

### Директива `is:inline`
Если вы хотите вставить сторонний скрипт (например, аналитику Google Analytics) и запретить Astro как-то его изменять или бандлить, используйте директиву `is:inline`.

```astro
<script is:inline src="https://example.com/analytics.js"></script>
```

## 2. Astro Острова (Astro Islands)

Писать Vanilla JS в тегах `<script>` отлично подходит для простых задач. Но для сложной интерактивности мы привыкли использовать фреймворки вроде React, Vue или Svelte.

Astro позволяет вам использовать **любые фреймворки вместе**, на одной странице! Это достигается благодаря архитектуре **Astro Islands (Острова)**.

Идея в том, что ваш сайт — это статичное HTML-море, в котором плавают "острова" интерактивности (компоненты React/Vue).

```astro
---
// Импортируем компонент React
import ReactCounter from '../components/ReactCounter.jsx';
---

<main>
  <h1>Мой сайт на Astro</h1>
  
  <!-- Этот компонент отрендерится как чистый HTML! -->
  <ReactCounter />
</main>
```

**Стоп!** По умолчанию, даже если вы импортировали React-компонент, Astro отрендерит его на сервере в чистый HTML и **вырежет весь JavaScript**. Кнопки в счетчике не будут нажиматься. 

Чтобы React-компонент ожил (произошла гидратация), вам нужно указать Astro, **когда именно** загружать JS для этого компонента.

## 3. Директивы гидратации (`client:*`)

Вы управляете загрузкой JavaScript с помощью специальных директив, которые вешаются на компонент:

- `client:load` — загрузит и выполнит JS немедленно при загрузке страницы. Полезно для критически важных элементов интерфейса (например, главное меню).
- `client:idle` — загрузит JS, когда браузер освободится от других важных задач (прокрутки, отрисовки). Идеально для некритичных элементов.
- `client:visible` — загрузит JS **только тогда, когда компонент появится в области видимости** пользователя (при скролле). Это магия! Вы экономите кучу трафика.
- `client:media="{запрос}"` — загрузит JS только на определенных экранах (например, только на мобильных телефонах).
- `client:only="react"` — вообще не будет рендерить HTML на сервере, всё будет отрендерено на клиенте.

### Пример использования Островов:

```astro
---
import HeaderMenu from '../components/HeaderMenu.jsx';
import ImageCarousel from '../components/ImageCarousel.vue';
import HeavyChatWidget from '../components/HeavyChatWidget.svelte';
---

<!-- Загрузится сразу -->
<HeaderMenu client:load />

<main>
  <!-- Загрузится, только когда пользователь доскроллит до карусели -->
  <ImageCarousel client:visible />
</main>

<!-- Загрузится, когда браузер будет свободен -->
<HeavyChatWidget client:idle />
```

Благодаря Островам, Astro позволяет вам строить сложные интерактивные приложения, не жертвуя производительностью и SEO!
